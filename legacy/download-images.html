Potters Bar Garage — Legacy Image Downloads

Use this page if download.sh could not download images programmatically. Open each image in a new tab, then right-click → Save image as… using the destination path shown.

Where to save each file: All paths are relative to legacy/pottersbargarage.co.uk/.
For example, wp-content/uploads/2022/04/Trade-association.png should be saved to:
/Users/tarnewestcott/Development/pottersbargarage/legacy/pottersbargarage.co.uk/wp-content/uploads/2022/04/Trade-association.png

After saving all images, run: git add legacy/ && git commit -m "Add legacy site mirror" && git push
